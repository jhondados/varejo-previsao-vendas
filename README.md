# 🛒 Previsão de Vendas no Varejo

> Previsão de vendas por loja, SKU e canal com IA. Antecipa demanda considerando sazonalidade, promoções e clima, otimizando estoque e reduzindo perdas.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/varejo-previsao-vendas/

[![Setor](https://img.shields.io/badge/Setor-Varejo-blue)]() [![IA](https://img.shields.io/badge/IA-Time%20Series-green)]() [![Demo](https://img.shields.io/badge/Demo-Interativa-orange)]() [![Dados](https://img.shields.io/badge/Dados-CSV%2FExcel-success)]()

## 📊 Resultados-chave (KPIs)
**4.6%** MAPE · **-32%** Ruptura · **-21%** Perda · **1.2M** SKUs

## 🧠 Tecnologias de IA
Time Series · LightGBM · Demand Forecasting

## ✨ O que faz
- Previsão por loja e SKU
- Impacto de promoções
- Sazonalidade e clima
- Otimização de estoque
- Redução de perdas

## 🗄️ Fonte de dados real
[IBGE/PMC + dados de venda](https://www.ibge.gov.br) — bases de entrada e resultados disponíveis para download em CSV/Excel no app.
